1. Cartesian-to-Polar Transmutation

          

            A satellite position in the canvas buffer is $(x, y)$. To command phased-array phase shifters, the radar converts this to polar coordinates relative to the station origin:
          

          

            dx = sat.x - originX;

            dy = -(sat.y - originY);

            r = Math.hypot(dx, dy);

            theta = Math.atan2(dy, dx);
          

        


        

          
2. Pure 2 Circle Loci & Range Gates

          

            

            Concentric range rings are circular loci (x - a)² + (y - b)² = R² representing distance thresholds (150 km, 300 km, 450 km, 600 km). When r ≤ 600 km, line-of-sight acquisition triggers.
          

          

            [80, 160, 240, 320].forEach(R => {

              ctx.arc(cx, cy, R, 0, Math.PI * 2);

            });
          

        


        

          
3. Doppler Shift Kinematics

          


            As a satellite cruises along its vector, slant range changes at rate dr/dt. If range is decreasing (Δr < 0), the carrier frequency blue-shifts (Δf > 0); as it recedes, it red-shifts:
          

          

            rangeRate = (currentR - lastR) / dt;

            dopplerShift_kHz = -(f0 * rangeRate) / c;
